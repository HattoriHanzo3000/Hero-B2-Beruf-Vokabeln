# Release Notes - Version 1.0.3

## Overview
This document contains the release notes for version 1.0.3 of Hero - Deutsch B2 Beruf.

**Release Date:** December 2, 2025  
**Build Number:** 4  
**Marketing Version:** 1.0.3

## What's New

### Major Features

#### Premium Subscription System
- **StoreKit Integration**: Full premium subscription implementation with StoreKit 2
- **3-Day Free Trial**: New users get 3 days of premium features for free
- **Premium Benefits**: Unlock all features including ad-free experience
- **PaywallView**: Beautiful, native iOS paywall interface
- **Subscription Management**: Easy subscription management in Settings

#### Progress Statistics
- **Ring Charts**: Beautiful visual representation of learning progress
- **Detailed Statistics**: Track mastered, reinforced, familiar, and wrong words
- **Readiness Percentage**: See your overall exam readiness score
- **Real-time Updates**: Statistics update automatically as you learn

#### PDF Export
- **Generate PDFs**: Export any word list to PDF format
- **Two-Column Layout**: Professional, print-ready format
- **Offline Study**: Study from printed PDFs anywhere
- **Complete Information**: Includes words, translations, examples, and explanations

#### Launch Screen
- **Mascot Welcome**: Beautiful launch screen featuring the Hero mascot
- **Brand Consistency**: Enhanced first impression and brand recognition

### Content Enhancements

#### Expanded Vocabulary
- **Chapters 4-12**: Complete content expansion with all sections (A-E)
- **Comprehensive Coverage**: Full B2 Berufssprachkurs curriculum coverage
- **User Translations**: Enhanced support for personal translations

#### Content Organization
- **Improved Structure**: Split large JSON files into organized chapter/section files
- **Faster Loading**: Optimized content loading and organization
- **Better Navigation**: Easier to find and access specific content

#### Adjectives Organization
- **Preposition-Based**: Organized adjectives by preposition for easier learning
- **Better Study Flow**: More intuitive organization matches learning patterns

### UI/UX Improvements

#### Enhanced Views
- **CockpitView**: Major enhancements for better user experience
- **FavoritesView**: Improved favorites functionality
- **WordsListView**: Significant updates and improvements
- **Statistics View**: New dedicated view for progress tracking

#### Visual Updates
- **Mascot Assets**: Updated mascot GIFs and images
- **Consistent Design**: Better visual consistency across the app
- **Enhanced Localization**: Improved bilingual support

### Technical Improvements

#### Code Quality
- **Hide Debug Features**: Removed debug buttons from production build
- **Better Architecture**: Improved code organization and structure
- **Performance**: Optimized loading and processing

#### Dependencies
- **StoreKit 2**: Modern subscription management
- **Updated Packages**: Latest package versions for stability
