# Release Notes - Version 1.0.2

## Overview
This document contains the release notes for version 1.0.2 of Hero - Deutsch B2 Beruf.

**Release Date:** November 27, 2025  
**Build Number:** 3  
**Marketing Version:** 1.0.2

## What's New

### Improvements
- **Fixed Adjectives Study Mode**: Adjectives flash cards now properly load and display translations in study mode
- **Enhanced Word of the Day**: Added adjectives with prepositions as the 14th section for Word of the Day selection
- **Improved UI Consistency**: Updated checkmark styling across all word categories (General Words, Verbs, Adjectives) for a more cohesive experience
- **Better Translation Updates**: Improved translation synchronization when adding or editing translations in word lists

### Bug Fixes
- Fixed issue where adjectives cards were not displaying translations even when translations were available
- Fixed study view loading all adjective words regardless of content availability - now only loads words with translations, synonyms, or explanations
- Improved translation update notifications to ensure study view refreshes correctly when translations are added

### Technical Updates
- Enhanced DataService to properly trigger change notifications when translations are updated
- Improved study view logic to match adjectives behavior with other word categories
- Updated checkmark colors to use system primary color for better light/dark mode support
- Standardized checkmark sizes across all list views
